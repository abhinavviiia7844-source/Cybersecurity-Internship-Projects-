# Secure Web Application

## Overview

This project demonstrates a basic secure web application developed using Python and Flask. It provides user registration, login, session management, and a dashboard for authenticated users.

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## Security Features

* Password hashing instead of storing passwords as plain text.
* Parameterized database queries to help prevent SQL injection.
* Session-based authentication.
* Protected dashboard for authenticated users.

## How to Run

1. Install Python.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Install the dependencies:

   `python -m pip install -r requirements.txt`

5. Start the application:

   `python app.py`

6. Open `http://127.0.0.1:5000` in your browser.
