# 🔐 Cybersecurity Internship Projects

Welcome to my Cybersecurity Internship Projects repository! This repository contains two beginner-friendly projects developed to explore web application security and machine learning for network intrusion detection.

## 📌 Projects

### 1. Secure Web Application

A Python Flask web application demonstrating basic authentication and web security concepts.

**Features**

* User registration and login
* Password hashing
* Session-based authentication
* SQLite database integration
* HTML and CSS user interface

**Technologies:** Python, Flask, SQLite, HTML, CSS

**Project Folder:** [`Secure-Web-Application/`](./Secure-Web-Application/)

### 2. ML-Based Network Intrusion Detection System

A machine learning project that demonstrates how a classification model can identify potentially suspicious network traffic using a synthetic educational dataset.

**Features**

* Synthetic network traffic data generation
* Data preprocessing
* Random Forest classification
* Model evaluation and confusion matrix
* Feature importance visualization
* Optional prediction export

**Technologies:** Python, Google Colab, Pandas, NumPy, Scikit-learn, Matplotlib

**Notebook:** [`ML_Intrusion_Detection_Colab.ipynb`](./ML_Intrusion_Detection_Colab.ipynb)

Open the notebook in Google Colab and select **Runtime → Run all** to execute it.

## 🛠️ Technologies Used

* Python
* Flask
* SQLite
* HTML and CSS
* Google Colab
* Scikit-learn
* Pandas and NumPy
* Matplotlib

## 🎯 Learning Objectives

* Understand basic web application authentication.
* Explore password hashing and session management.
* Learn fundamental cybersecurity concepts.
* Apply machine learning to a network intrusion detection example.
* Evaluate classification models using performance metrics.
* Practice Python programming and project documentation.

## ⚠️ Disclaimer

These projects are intended for educational purposes. The intrusion detection project uses synthetic data and is not a production-ready security system. The web application should undergo additional security testing before deployment.

Do not upload real user information, passwords, secret keys, or sensitive database files to a public repository.
