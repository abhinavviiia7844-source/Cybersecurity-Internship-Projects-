# Secure Web Application

## Overview

A beginner-friendly cybersecurity project built using Python, Flask, and SQLite. It demonstrates basic web application security concepts through a registration and login system.

## Features

* User registration and login
* Password hashing
* Session-based authentication
* SQLite database integration
* HTML and CSS interface

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## Installation

1. Install Python.

2. Clone or download this repository.

3. Open a terminal in the project directory.

4. Install the required packages:

   `pip install -r requirements.txt`

5. Start the application:

   `python app.py`

6. Open the local address shown in the terminal in your browser.

## Security Notes

This project is intended for educational purposes. Before deployment, review session security, input validation, CSRF protection, and database security. Never store passwords in plain text or commit real user credentials.

## Learning Outcomes

* Understanding authentication workflows
* Learning password hashing
* Working with Flask and SQLite
* Exploring basic web application security
